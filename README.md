# Архангельск Рыбалка Бот (Arkhangelsk Fishing Bot)

Telegram-бот и панель координации рыбаков в Архангельске (Северная Двина, Белое Море, Сухое Море).

## Возможности

- **Интерактивный симулятор бота**: эмуляция сообщений в группе и личных сообщениях боту.
- **Журнал записей (Docs Log)**: фиксация сообщений, отправки точек и результатов голосования.
- **Карта рыбных точек**: отправка и просмотр координат рыбных мест Поморья (Мудьюг, Маймакса, Ягры, Никольское устье).
- **Экипаж выезда**: голосование участников за поездку (`vote_yes` / `vote_no`).
- **Очередь команд Spark**: интеграция с очередью задач и отслеживание статуса доставки.
- **Webhook API**: поддержка входящих вебхуков Telegram (`POST /api/telegram/webhook`).

## Конфигурация (.env)

- `TELEGRAM_BOT_TOKEN`: токен бота от @BotFather
- `TELEGRAM_CHAT_ID`: ID целевого чата рыбаков
- `LOG_DOC_ID`: ID документа для журнала
- `QUEUE_DOC_ID`: ID документа очереди Spark

## Запуск

```bash
npm run dev
```

Dev-сервер запускается на порту `3000`.
